# Ahmed's 5-Day Lift 💪

A simple phone workout app for a push / pull / legs / upper / lower split.

**Open it:** https://ahmedbalani.github.io/ahmed/

- Tap a day, then tap an exercise to see a short form video, a muscle map and form tips.
- Log weight × reps for each set. Empty boxes use last time's numbers, so you can just tap ✓.
- When you hit the top of the rep range on every set, the app tells you to add weight.
- Ticking a set starts a rest timer.
- Your logs are saved on your phone. Tap **Save backup** every week or two.

Tip: in Safari, tap Share → **Add to Home Screen** so it opens like a normal app.

One file (`index.html`), no build step. See `APP.md` for how it's built.
